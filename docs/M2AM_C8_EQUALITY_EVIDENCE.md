## The exact question, not a repetition of loop arithmetic

MSM66201 / nX-8/200 JC GT is **C8 rel8**. The first-edition September1991
instruction manual, printed3-66, prints `(ZF=0) OR (CF=0)`; the unchanged
executor implements `(ZF=0) AND (CF=0)`. Native unsigned word CMP gives:

| CMP result | CF | ZF | Printed OR | Existing AND |
|---|---|---|---|---|
|Greater|0|0|Taken|Taken|
|Equal|0|1|Taken|Not taken|
|Less|1|0|Taken|Not taken|

CF1/ZF1 is not an ordinary result of that CMP. The mnemonic's conventional
meaning, program intent and an emulator implementation are not silicon proof.
No predicate is selected, corrected or dynamically admitted in this milestone.
